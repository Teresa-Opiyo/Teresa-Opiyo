# Hi, I'm Teresa Akumu Opiyo

**Project management professional | Dashboards, AI tools and coordination | Germany**

I help teams run projects clearly: planning and tracking work, organising events and workshops, turning data into dashboards and using AI tools responsibly to save time. I have worked in international organisations across Germany, Kenya and Hungary, including Welthungerhilfe, the African Wildlife Foundation and UNHCR.

## What I work on
- **Project coordination:** plans, budgets, trackers, donor and stakeholder reporting
- **Dashboards:** interactive Power BI dashboards (maps and heat maps) and Excel dashboards with pivot tables that refresh automatically
- **Training:** helping teams build their own dashboards and use AI tools to write reports and presentations faster
- **Events and communications:** workshops, webinars, training events and clear messaging
